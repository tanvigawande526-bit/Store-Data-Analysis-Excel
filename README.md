# Store Data Analysis Dashboard

## 📊 Project Overview
This project presents an interactive Store Data Analysis Dashboard created using Microsoft Excel.

The dashboard helps analyze sales performance and provides insights into different aspects of store data.

## 🛠️ Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Data Cleaning
- Data Analysis

## 📈 Dashboard Features
- Sales and Profit Analysis
- Region-wise Analysis
- Category-wise Analysis
- Monthly Sales Analysis
- Interactive Filters and Slicers
- Visual Charts and KPIs

The complete Excel dashboard is available in this repository:
